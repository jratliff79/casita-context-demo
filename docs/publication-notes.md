# Public examples and historical evidence

Current examples use generic synthetic actors, team names and application
boundaries. Only synthetic fixtures or explicitly allowlisted public licensed
source belong in this repository. Generated stores, credentials, native state,
raw operator receipts and local paths remain outside tracked examples. Review
outbound code, prose, screenshots, PR descriptions and commit metadata before
publication; ignored output alone is not a content review.

[Publication projections](publication-projections.json) identify three historical
records whose current public presentation differs from the original bytes:

- Two validation summaries generalize identifying field names and preserve every
  recorded value, source/build pin, date, measurement and negative control under
  `record`. `new_validation_run: false` distinguishes them from new receipts.
- The documentation review omits one identifying citation. Both findings and
  recommendation text, the other 12 citations, immutable source commit, context
  ID and directory key remain unchanged. The source allowlist pins the projected
  report digest. Replay still rejects substituted bytes and checks every retained
  citation against the original Git blobs, with all seven negative controls.
  `new_ai_review: false` distinguishes the projection from another review.

The manifest records original and projected SHA-256 digests. Historical videos
and receipts still describe their original runs. Selected original records are
retained privately for comparison. This cleanup does not rewrite published Git
history, pinned source snapshots, cached copies or older PR references, and does
not claim those historical copies were erased.

New commits from this checkout use the repository owner's GitHub noreply
identity. That local setting does not alter existing commit metadata or configure
other contributors' clones.
